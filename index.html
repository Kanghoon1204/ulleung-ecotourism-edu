오늘 수업은 이렇게 갑니다

AI 도구 이름을 많이 외우는 시간이 아닙니다. 내 일에 바로 쓸 홍보자료를 하나씩 완성하는 시간입니다.

요즘 AI로 실제로 할 수 있는 일

  • 가게 소개글, SNS 글, 영어 안내문을 빠르게 초안으로 만들 수 있습니다.
  • 포스터 이미지, 홍보 문구, 영상에 넣을 짧은 음악 아이디어를 만들 수 있습니다.
  • 내 자료를 넣고 음성 소개처럼 들어보며 좋은 표현을 다시 고를 수 있습니다.
  • 말로 원하는 화면을 설명해서 간단한 웹페이지 파일을 만들고 고칠 수 있습니다.

바이브 코딩은 이렇게 이해하면 됩니다

코드를 외워서 직접 치는 방식이 아니라, 만들고 싶은 화면을 말로 설명하고 AI가 만든 결과를 보며 다시 고치는 방식입니다.

  • 처음부터 완벽하게 말하지 않아도 됩니다.
  • 결과를 보고 “글자를 더 크게”, “전화 버튼을 위로”, “울릉도 느낌을 더 살려줘”처럼 다시 요청합니다.
  • 마지막에는 사람이 사실 정보와 화면을 직접 확인합니다.
시작
AI로 무엇을 할 수 있는지 감을 잡습니다

글, 이미지, 음성, 음악, 웹페이지가 어떻게 연결되는지 짧게 보고 바로 실습으로 넘어갑니다.

기초 입력
내 가게 정보를 한 번만 정리합니다

이름, 위치, 대표 메뉴, 장점, 문의 방법을 적어두면 모든 복사 문장에 자동으로 들어갑니다.

콘텐츠

소개글, SNS 글, 영어 안내문, 포스터 문구를 만들고 마음에 드는 한 줄 소개를 고릅니다.

확장
NotebookLM과 Suno로 소리까지 넓힙니다

내 자료를 음성 소개로 들어보고, 짧은 홍보 영상에 어울리는 BGM 아이디어도 만들어봅니다.

완성
Codex로 우리 가게 소개 페이지를 만듭니다

오늘 만든 글, 포스터 아이디어, 음성 표현을 모아 브라우저에서 열 수 있는 웹페이지 파일로 정리합니다.

오늘의 기준: 잘 만든 결과물은 멋진 말보다 정확한 정보가 먼저입니다. AI가 만든 내용은 초안으로 보고, 공개 전에는 직접 확인합니다.
1

수업 시작 전에 열어둘 것

로그인이 필요한 화면은 미리 열어두면 실습이 끊기지 않습니다.

Gemini

소개글, SNS 글, 번역, 포스터 이미지를 만들 때 사용합니다.

NotebookLM

내 자료를 넣고 Audio Overview로 음성 소개를 들어봅니다.

Suno

홍보 영상이나 매장 안내에 쓸 짧은 배경음악 아이디어를 만듭니다.

Codex

우리 가게 소개 웹페이지 파일을 만들고 수정할 때 사용합니다.

수업 규칙: AI가 만든 결과는 초안입니다. 가격, 전화번호, 운영시간, 배편, 주소는 공개 전에 사람이 직접 확인합니다.
2

내 가게 정보를 적습니다

모르는 칸은 비워도 됩니다. 나중에 AI에게 추천해달라고 해도 괜찮습니다.

3

Gemini로 소개글을 만듭니다

여기서 나온 제목과 한 줄 소개는 포스터와 웹페이지에 다시 씁니다.

1Gemini를 엽니다.
2아래 버튼 중 하나를 눌러 복사하고 Gemini 입력창에 붙여넣습니다.
3마음에 드는 제목 1개와 한 줄 소개 1개를 골라 메모합니다.
너는 울릉도 관광 홍보 전문가야. 아래 정보를 바탕으로 우리 가게 홍보자료를 만들어줘. [내 정보] - 이름: [가게/숙소/프로그램 이름] - 종류: [식당/숙소/체험/관광지/특산품] - 위치: [위치] - 대표 메뉴/서비스: [대표 메뉴, 객실, 체험, 가격] - 장점: [강조하고 싶은 특징] - 문의: [전화번호 또는 문의 방법] [만들어줄 것] 1. 첫 화면에 넣을 큰 제목 5개 2. 한 줄 소개 5개 3. 인스타그램 글 1개 4. 외국인 관광객용 영어 안내 3줄 5. 자주 묻는 질문 5개와 답변 조건: - 중학생도 이해할 수 있게 쉽게 - 너무 과장하지 않기 - 실제 확인이 필요한 가격, 시간, 배편 정보는 "확인 필요"라고 표시하기
4

AI 포스터를 만듭니다

직접 찍은 사진이 있으면 Gemini에 사진을 올리고 “이 사진을 참고해서”라고 추가합니다.

우리 가게 홍보 포스터 이미지를 만들어줘. 주제: - 이름: [가게/숙소/프로그램 이름] - 종류: [식당/숙소/체험/관광지/특산품] - 대표 매력: [바다 전망, 자연산 음식, 성인봉 트레킹, 가족 체험 등] 포스터에 넣을 문구: "[한 줄 소개]" 이미지 분위기: - 울릉도 바다와 자연이 느껴지게 - 밝고 선명한 색감 - 관광 홍보 포스터 스타일 - 글자가 너무 많지 않게 - 세로 비율 3:4 주의: - 실제 로고나 실제 인물 얼굴은 넣지 말아줘 - 읽기 쉬운 큰 글씨로 만들어줘
확인: AI 이미지는 글자가 틀릴 수 있습니다. 전화번호, 가격, 상호가 이미지 안에 들어가면 반드시 다시 확인합니다.
5

NotebookLM으로 음성 소개를 실제로 재생합니다

Gemini가 만든 글을 NotebookLM에 넣고, Audio Overview를 만들어 들어봅니다. 좋은 표현은 다시 홍보문구로 가져옵니다.

1NotebookLM에서 새 노트북을 만듭니다.
2Gemini가 만든 소개글, 메뉴 설명, FAQ를 소스로 붙여넣습니다.
3Studio 패널에서 Audio Overview를 생성합니다.
4생성된 음성을 30초 정도 실제로 재생합니다. 말투, 속도, 소개 순서를 들어봅니다.
5좋은 표현 3개를 메모하고, 웹페이지 제목이나 SNS 글에 다시 씁니다.
캡처 자리 1
소스 붙여넣기 화면

나중에 Gemini 소개글을 NotebookLM 소스로 넣는 화면 캡처를 넣습니다.

캡처 자리 2
Audio Overview 생성 화면

Studio 패널에서 Audio Overview를 누르는 장면을 넣습니다.

캡처 자리 3
재생 버튼 화면

수업 중 실제로 음성을 재생하는 화면을 넣습니다.

이 자료를 바탕으로 우리 가게를 처음 듣는 관광객도 이해할 수 있게 설명해줘. 원하는 방향: - 너무 광고처럼 말하지 않기 - 울릉도 여행자가 궁금해할 정보를 먼저 말하기 - 위치, 대표 메뉴/서비스, 이용 팁, 문의 방법을 쉽게 설명하기 - 3분 안에 들을 수 있는 편안한 소개 느낌 - 좋은 표현 3개를 마지막에 따로 정리하기
6

Suno AI로 짧은 홍보 BGM을 만듭니다

포스터나 웹페이지를 만든 뒤, SNS 영상이나 매장 안내에 어울리는 짧은 배경음악을 만들어봅니다. 자세한 화면 캡처는 나중에 추가할 수 있게 자리를 만들어두었습니다.

1Suno를 열고 로그인합니다.
2아래 명령문을 복사해서 음악 생성 입력창에 붙여넣습니다.
3음악이 만들어지면 10초에서 20초 정도 들어보고, 우리 가게 분위기와 맞는지 확인합니다.
4마음에 드는 음악 제목, 분위기, 사용 위치를 메모합니다. 예: 인스타 영상, 매장 안내 영상, 웹페이지 배경 아이디어.
캡처 자리 1
Suno 입력창

음악 분위기를 입력하는 화면 캡처를 넣습니다.

캡처 자리 2
생성된 음악 목록

결과가 1개 이상 생성된 화면을 넣습니다.

캡처 자리 3
재생·저장 화면

수업 중 실제로 음악을 재생하는 장면을 넣습니다.

울릉도 관광 홍보 영상에 사용할 짧은 배경음악을 만들어줘. 분위기: - 밝고 따뜻한 여행 느낌 - 울릉도 바다, 산책, 자연, 신선한 음식이 떠오르게 - 너무 시끄럽지 않고, 설명 음성과 함께 써도 방해되지 않게 - 30초 정도의 짧은 홍보 영상 배경음악 느낌 스타일: - instrumental - acoustic guitar, light percussion, warm bass - clean, hopeful, coastal travel mood 주의: - 특정 유명 가수나 기존 노래를 따라 하지 말기 - 가사가 꼭 필요하지 않으면 보컬 없이 만들기
확인: 음악을 실제 홍보물에 쓰기 전에는 Suno 계정의 사용 조건과 상업적 사용 가능 여부를 확인합니다.
7

Codex로 우리 가게 소개 페이지를 만듭니다

오늘의 최종 실습입니다. Codex에게 HTML 파일을 만들게 하고, 브라우저에서 열어 확인합니다.

1Codex 앱을 열고 새 폴더를 선택합니다. 설치가 필요하면 Codex 시작 안내를 참고합니다.
2아래 명령문을 복사해서 Codex 입력창에 붙여넣습니다.
3완성된 index.html을 브라우저에서 열고, 글자·버튼·연락처·모바일 화면을 확인합니다.
우리 가게 소개 웹페이지 파일을 만들어줘. 작업 방식: - 파일 이름은 index.html로 해줘. - HTML, CSS, JavaScript를 한 파일에 넣어줘. - 별도 서버 없이 브라우저에서 바로 열 수 있게 만들어줘. - 완성 후 모바일 화면에서도 글자와 버튼이 겹치지 않는지 확인해줘. [기본 정보] - 이름: [가게/숙소/프로그램 이름] - 종류: [식당/숙소/체험/관광지/특산품] - 위치: [위치] - 대표 메뉴/서비스: [대표 메뉴, 객실, 체험, 가격] - 장점: [강조하고 싶은 특징] - 문의: [전화번호 또는 문의 방법] - 한 줄 소개: [Gemini에서 고른 한 줄 소개] [페이지 구성] 1. 첫 화면: 큰 제목, 한 줄 소개, 대표 이미지 영역, 문의 버튼 2. 핵심 매력 3가지 3. 대표 메뉴/서비스 3~5개 4. 처음 방문하는 사람을 위한 이용 팁 5. 외국인 관광객용 영어 안내 3줄 6. 자주 묻는 질문 5개 7. 오시는 길과 문의 정보 [디자인] - 울릉도 바다색과 따뜻한 레드오렌지 포인트 - 글자는 크게 - 모바일에서 먼저 보기 좋게 - 버튼은 "전화 문의", "지도 보기", "예약 문의"처럼 바로 행동할 수 있게 [주의] - 확인되지 않은 가격, 배편, 운영시간은 "확인 필요"라고 표시 - 사진은 임시 영역으로 두고, 나중에 직접 찍은 사진을 넣을 수 있게

공개 전에 마지막으로 확인합니다

AI가 만든 초안을 그대로 공개하지 않습니다. 아래 항목을 직접 확인합니다.

수정 문장

이 웹페이지를 공개하기 전에 점검해줘. 확인할 것: - 가격, 운영시간, 위치, 전화번호가 틀릴 가능성 - 너무 과장된 표현 - 사진 저작권 문제 - 모바일에서 글자나 버튼이 겹치는 부분 - 외국어 번역이 어색한 부분 표로 정리하고, 내가 직접 확인해야 할 항목을 따로 표시해줘.

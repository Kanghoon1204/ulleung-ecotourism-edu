AI TOOLS

오늘 사용할 AI 도구 3가지

세 가지 도구가 각자 다른 역할을 합니다. Gemini로 재료를 만들고, Scout로 참고하고, Antigravity로 조립해요.

✨

Google Gemini

글과 이미지를 만들어주는 AI 비서

구글이 만든 AI 서비스입니다. 대화하듯이 요청하면 홍보 문구, 번역, 이미지까지 만들어줍니다. 무료로 사용할 수 있어요.

✓ 관광 홍보 문구를 한국어·영어·일본어로 작성
✓ 관광 포스터·카드뉴스 이미지 자동 생성
✓ 블로그·SNS 글 초안 작성 도우미
✓ 외국어 번역 및 자연스러운 표현 교정
시작하려면? gemini.google.com 접속 → 구글 계정 로그인 → 바로 사용!
🔍

Scout

좋은 사례를 찾아주는 AI 리서처

다른 지역의 관광 홍보 사례를 AI가 찾아서 분석해줍니다. "잘 된 곳은 어떻게 했는지" 참고하여 우리 콘텐츠를 개선할 수 있어요.

✓ 제주, 거제, 강릉 등 타 지역 관광 홍보 사례 자동 검색
✓ 잘 만든 홍보물의 특징과 패턴 분석
✓ 우리 콘텐츠에 적용할 개선 포인트 추천
✓ 요즘 뜨는 관광 키워드·해시태그 찾기
활용 포인트 "다른 데는 어떻게 하고 있지?" → Scout가 찾아서 정리해줍니다
🚀

Google Antigravity

말로 웹사이트를 만드는 AI 도구

코딩을 전혀 몰라도 됩니다. "이런 웹페이지 만들어줘"라고 말하면 AI가 웹사이트를 자동으로 만들어줍니다. 수정도 대화로 합니다.

✓ "~한 페이지 만들어줘" 한 마디로 웹사이트 생성
✓ "색상 바꿔줘" "사진 추가해줘" 대화로 수정
✓ Gemini로 만든 텍스트·이미지를 바로 넣을 수 있음

PROMPT EXAMPLES

이대로 따라 입력해 보세요

교육 중 실제로 사용할 프롬프트입니다. 복사해서 붙여넣기만 하면 됩니다. 그 다음에 나만의 버전으로 바꿔보세요!

1

관광 홍보 문구 만들기

Gemini
너는 울릉도 전문 관광 홍보 카피라이터야. 성인봉(해발 984m)을 소개하는 인스타그램 홍보 문구를 3가지 써줘. 조건: - 20~30대 여행자가 가고 싶어지게 - 감성적이면서 정보도 포함 - 해시태그 5개씩 달아줘 - 한국어, 영어, 일본어 각각 작성
왜 이렇게 쓰나요? "역할 부여(관광 카피라이터)" + "타겟 지정(20~30대)" + "톤 지정(감성적)" + "조건 명시" — 이 4가지를 넣으면 AI가 훨씬 잘 만듭니다.
2

홍보 이미지 만들기

Gemini
울릉도 해안 절벽과 에메랄드빛 바다가 보이는 풍경 이미지를 만들어줘. 스타일: 여행 잡지 표지 느낌 분위기: 맑고 청량한 여름날 텍스트 포함: "ULLEUNGDO" 비율: 인스타그램 정사각형(1:1)
꿀팁! "스타일" "분위기" "비율"을 구체적으로 말해줄수록 원하는 이미지에 가까워집니다. 마음에 안 들면 "좀 더 밝게" "색감을 따뜻하게" 추가 요청해보세요.
3

관광 사례 분석하기

Scout
제주도, 거제도, 강화도의 관광 홍보 웹사이트를 분석해줘. 비교해줄 항목: - 메인 페이지 첫 화면 구성 - 외국어 지원 (영어, 일본어, 중국어) - SNS 연동 방식 - 예약/문의 시스템 울릉도 관광 홍보 페이지에 적용할 수 있는 개선 아이디어 5가지 추천해줘.
이게 왜 중요한가요? "잘 되는 곳이 어떻게 하는지" 먼저 보면, 우리가 만들 페이지에 바로 좋은 아이디어를 적용할 수 있습니다.
4

웹페이지 만들기

Antigravity
울릉도 관광 홍보 웹사이트를 만들어줘. 구성: - 첫 화면: 바다 느낌, "신비의 섬 울릉도" - 관광 명소 4곳 카드형 소개 - 울릉도 맛집 & 특산물 - 오시는 길 (포항/강릉→울릉도) - 문의처와 전화번호 디자인: 깔끔하고 모던하게 색상: 파란색+초록색 계열 한국어와 영어 둘 다 표시해줘
핵심! "어떤 섹션이 필요한지" 구체적으로 나열하면 원하는 구성에 가까운 페이지가 나옵니다. 생성 후에 "명소를 6곳으로 늘려줘" 같은 수정도 가능해요.
EXERCISES

조별 실습 과제

5~6명이 한 조가 되어 하루 동안 함께 웹페이지를 완성합니다. 역할을 나눠서 협력해 보세요!

1

오전 과제 — 웹페이지에 들어갈 재료 만들기

Gemini·Scout를 활용하여 텍스트·이미지 소재를 준비합니다

  1. 조별 주제 정하기: 울릉도 전체 소개 / 특정 명소 집중(성인봉, 독도 등) / 맛집·체험 특화 / 내 사업체 홍보 중 택 1
  2. 홍보 문구 3세트 만들기: 메인 타이틀 + 서브 카피 + 상세 소개글 (한국어 필수, 영어·일본어 중 택 1 이상)
  3. 이미지 4장 이상 만들기: 메인 배너 1장 + 소개 카드용 이미지 3장 이상
  4. Scout로 벤치마킹: 타 지역 관광 사이트를 분석하고, 우리 페이지에 적용할 아이디어 3가지 정리
  5. 소재 폴더 정리: 만든 텍스트·이미지를 한 곳에 모아서 오후 실습 준비 완료!
2

오후 과제 — 웹페이지 만들고 배포하기

Antigravity로 오전에 만든 소재를 활용한 관광 홍보 웹페이지를 완성합니다

  1. Antigravity에 프롬프트 입력: 주제·구성·디자인 방향을 적어서 첫 번째 페이지 생성
  2. 오전 소재 넣기: Gemini로 만든 홍보 문구와 이미지를 웹페이지에 삽입
  3. Scout 분석 반영: 오전에 찾은 벤치마킹 아이디어를 페이지에 적용
  4. 디자인 다듬기: 색상, 폰트, 레이아웃을 대화로 수정 요청
  5. 모바일 확인 + 다국어 확인: 스마트폰에서도 잘 보이는지, 외국어가 자연스러운지 점검
  6. 배포: 공유 링크 생성 → QR코드로 만들기 → 발표 준비
3

발표 — 우리가 만든 것을 자랑해요

조별로 완성한 웹페이지를 발표하고 서로 피드백합니다

  1. 발표 (조당 5분): 어떤 주제를 골랐고 → 어떤 프롬프트를 썼고 → 완성된 웹페이지 시연
  2. Q&A (조당 3분): 다른 조와 강사님이 질문
  3. 투표: "가장 가보고 싶어지는 페이지" 참가자 상호 투표
  4. 우수 사례 시상: 콘텐츠 완성도 · 디자인 · 창의성 부문별 시상

FAQ

자주 묻는 질문

궁금한 점이 있으시면 편하게 문의해 주세요!

컴퓨터를 잘 못하는데 따라갈 수 있을까요? ▼
네, 충분히 가능합니다! 이번 교육은 AI를 처음 접하는 분을 기준으로 설계했습니다. "생성형 AI가 뭔지"부터 시작하고, 모든 단계를 강사와 함께 화면을 보며 진행합니다. TA(보조 강사)가 각 테이블을 돌면서 1:1로 도와드리니 걱정 마세요.
구글 계정이 없는데 어떻게 하나요? ▼
교육 시작 전(09:00~09:10)에 구글 계정 만드는 시간을 드립니다. 또는 미리 만들어오시면 더 좋습니다. Gmail 주소가 있으면 이미 구글 계정이 있는 것입니다!
노트북이 없는데 참여할 수 있나요? ▼
네, 울릉고등학교 전산실 PC를 사용하실 수 있습니다. 다만 개인 노트북을 가져오시면 교육 후에도 집에서 바로 실습해보실 수 있어서 더 좋습니다.
만든 웹페이지를 교육 후에도 사용할 수 있나요? ▼
네! Antigravity에서 만든 웹페이지는 교육 후에도 계속 접속·수정·공유할 수 있습니다. 실제 사업 홍보에 바로 활용해보세요. 내용을 바꾸고 싶을 때는 다시 접속해서 대화로 수정하면 됩니다.
AI 도구들은 비용이 드나요? ▼
교육에서 사용하는 기능은 모두 무료 범위 내에서 진행합니다. Gemini는 무료로 사용할 수 있고, Antigravity도 기본 기능은 무료입니다. 더 고급 기능이 필요한 경우 유료 플랜이 있지만, 오늘 교육에서는 무료 기능만으로 충분합니다.
2회차 교육은 언제인가요? ▼
2회차(후반기)는 "온라인 플랫폼 활용 홍보 전략 실습"을 주제로 진행됩니다. 1회차에서 만든 웹페이지를 SNS, 네이버, 구글 등에 효과적으로 홍보하는 방법을 배웁니다. 구체적인 일정은 1회차 교육 시 안내드립니다.

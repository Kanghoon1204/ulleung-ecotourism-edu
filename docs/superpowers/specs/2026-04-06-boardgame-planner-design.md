# 보드게임 기획서 생성기 (Board Game Planner Generator)

## 개요

보드게임 기획서를 AI가 생성해주는 단일 HTML 페이지.
**관광 테마 토글(ON/OFF)** 로 울릉도 관광 콘텐츠 연계 모드와 일반 보드게임 모드를 전환.
교육 워크숍 수업 교재로 사용하며, 기존 GitHub Pages 사이트에 배포.

## 핵심 흐름

```
[관광 테마 ON/OFF] → [Wizard 입력 3단계] → [Scout API 호출] → [기획서 카드형 표시]
                                                                       ↓
                                                          [수정 요청 입력] → [재생성]
                                                                ↑                |
                                                                └────────────────┘
```

## 기술 스택

- 단일 HTML 파일 (인라인 CSS/JS) — 기존 프로젝트 패턴 준수
- CSS 변수: 기존 `:root` 디자인 토큰 재사용
- Scout API: OpenRouter 직접 호출 (fetch, 교육용 고정 키 내장)
- 폰트: Noto Sans KR (Google Fonts)
- 마크다운 렌더링: 정규식 기반 간이 파서 (외부 라이브러리 없음)

## 관광 테마 토글

페이지 상단에 ON/OFF 스위치.

| 모드 | 동작 |
|------|------|
| **ON (관광 테마)** | Step 1에 울릉도 관광지 드롭다운 표시, Step 3에 마케팅 목표 표시, 결과에 "관광 마케팅 연계" 카드 포함 |
| **OFF (일반 보드게임)** | Step 1에서 관광지 대신 자유 테마 입력만 표시, Step 3에서 마케팅 목표 숨김, 결과는 4개 카드 (마케팅 카드 제외) |

토글 변경 시 Wizard가 Step 1으로 리셋.

## UI 구조

### 1. Wizard 입력 (3 단계)

스텝 프로그레스바(1─2─3) + 이전/다음 버튼. 한 번에 한 단계만 표시.
이전 버튼으로 돌아가면 입력값 유지. 필수 필드 미입력 시 다음 버튼 비활성.

#### Step 1: 테마 설정

**관광 모드 ON:**

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 관광지 | 체크박스 그룹 | 1개 이상 | 성인봉, 봉래폭포, 독도, 나리분지, 저동항, 도동항, 태하향목, 천부항, 죽도, 관음도, 행남해안산책로, 사자바위 |
| 직접 입력 | 텍스트 | 선택 | 목록에 없는 관광지 추가 |
| 테마 키워드 | 태그 클릭 + 자유 입력 | 선택 | 자연, 모험, 역사, 음식, 해양 등 |

**관광 모드 OFF:**

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 게임 테마 | 텍스트 | 필수 | 자유 입력 (예: "우주 탐험", "좀비 서바이벌") |
| 테마 키워드 | 태그 클릭 + 자유 입력 | 선택 | 판타지, SF, 공포, 힐링, 경쟁 등 (일반 키워드 세트) |

#### Step 2: 게임 설정

| 필드 | 타입 | 필수 | 기본값 | 설명 |
|------|------|------|--------|------|
| 게임 장르 | 드롭다운 | 필수 | 전략 | 전략 / 퀴즈 / 협동 / 모험 / 수집 / 레이싱 / 추리 / 덱빌딩 |
| 인원 | 숫자 입력 (min/max) | 필수 | 2~4명 | 최소 인원, 최대 인원 |
| 플레이 타임 | 라디오 | 필수 | 30분 | 15분 / 30분 / 60분 / 90분+ |
| 난이도 | 라디오 | 필수 | 보통 | 입문 / 보통 / 전략가 |

**자동 추천 버튼**: Step 1 입력 기반으로 장르/난이도를 하드코딩 매핑으로 자동 채움.
- 관광 모드 ON + 독도 → 모험/퀴즈 추천
- 관광 모드 OFF + "우주" → SF/전략 추천
- 매핑에 없는 경우: 기본값 유지, "직접 선택해주세요" 안내

#### Step 3: 대상 & 부가 설정

| 필드 | 타입 | 필수 | 설명 |
|------|------|------|------|
| 타겟 연령대 | 체크박스 | 1개 이상 | 어린이(7~12) / 청소년(13~18) / 성인(19+) / 전연령 |
| 마케팅 목표 (관광 ON만) | 체크박스 | 선택 | 관광 홍보 / 교육 / 체험 연계 / 기념품 판매 / SNS 바이럴 |
| 추가 요청사항 | 텍스트 에어리어 (max 500자) | 선택 | 자유롭게 원하는 요소 기술 |

### 2. 생성 중 상태

- CSS 애니메이션 스피너 + "AI가 기획서를 작성하고 있습니다..." 메시지
- 30초 이상 시 "조금 더 걸리고 있어요..." 표시
- 에러 시: "생성에 실패했습니다. 다시 시도해주세요." + 재시도 버튼

### 3. 기획서 결과 (카드형 표시)

**관광 모드 ON: 5개 카드 / OFF: 4개 카드**

#### 카드 1: 게임 개요
게임 제목, 한줄 컨셉, 스토리 배경, 테마 설명

#### 카드 2: 게임 규칙
승리 조건, 턴 진행 방식, 핵심 메커니즘, 특수 규칙

#### 카드 3: 구성품 목록
보드, 카드 종류/수량, 토큰, 주사위, 기타 구성품 상세

#### 카드 4: 밸런스 분석 & 보완 제안
AI의 자체 밸런싱 분석, 운/실력 비율, 개선 제안

#### 카드 5: 관광 마케팅 연계 (관광 ON만)
실제 관광지와의 연결 방안, SNS 활용법, 오프라인 체험 연계

각 카드: 복사 버튼 (클립보드 복사 + "복사됨!" 토스트 1.5초)

### 4. 수정 → 재생성 루프

결과 하단:
- **수정 요청 입력란** (텍스트 에어리어, max 500자)
  - 플레이스홀더: "규칙을 더 단순하게 해줘", "퀴즈 요소를 추가해줘"
- **재생성 버튼**

재생성 프롬프트 구조:
```
[시스템 프롬프트]

이전에 생성한 기획서:
---
{이전 기획서 전문}
---

사용자 수정 요청:
{수정 요청 텍스트}

위 수정 요청을 반영하여 기획서를 다시 작성해줘. 동일한 섹션 구조를 유지할 것.
```

## Scout API 연동

### 요청

```javascript
fetch("https://openrouter.ai/api/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": "Bearer {EMBEDDED_KEY}",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    model: "meta-llama/llama-4-scout",
    messages: [
      { role: "system", content: SYSTEM_PROMPT },
      { role: "user", content: userPrompt }
    ],
    max_tokens: 4000,
    temperature: 0.7
  })
})
```

### 시스템 프롬프트

```
너는 보드게임 기획 전문가야.
사용자가 제공한 정보를 바탕으로 완성도 높은 보드게임 기획서를 작성해.
반드시 아래 섹션 구조로, 각 섹션을 ## 마크다운 헤더로 구분해서 출력해:

## 게임 개요
## 게임 규칙
## 구성품 목록
## 밸런스 분석
{관광 모드 ON이면: ## 관광 마케팅 연계}

각 섹션 내에서 소제목은 ### 사용. 리스트는 - 사용.
한국어로 작성. 실제 제작 가능한 수준의 구체적인 내용을 포함할 것.
```

### 응답 파싱

Scout 응답에서 `## ` 헤더 기준으로 섹션을 분리하여 각 카드에 매핑.
간이 마크다운 렌더링: `##`→h3, `###`→h4, `**bold**`, `- list`, `` `code` ``

파싱 실패 시: 전체 텍스트를 단일 카드에 표시 + "섹션 구분에 실패했습니다" 안내.

### 에러 처리

| 상황 | 동작 |
|------|------|
| 네트워크 에러 | "네트워크 오류. 인터넷 연결을 확인해주세요." + 재시도 버튼 |
| 429 Rate Limit | "요청이 많습니다. 30초 후 다시 시도해주세요." + 자동 카운트다운 |
| 500 서버 에러 | "서버 오류. 잠시 후 다시 시도해주세요." + 재시도 버튼 |
| 빈 응답 | "AI가 응답을 생성하지 못했습니다." + 재시도 버튼 |
| 타임아웃 (60초) | fetch AbortController로 중단 + 재시도 안내 |

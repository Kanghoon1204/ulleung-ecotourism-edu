0 AI 시작하기 — Gemini & ChatGPT 접속 방법

컴퓨터를 켜는 것부터 첫 대화까지, 하나하나 따라해 봅시다. 천천히 따라오시면 됩니다!

0-1. 크롬(Chrome) 브라우저 열기

AI 서비스를 사용하려면 인터넷 브라우저가 필요합니다. 크롬 브라우저를 사용하는 것이 가장 안정적입니다.

1

바탕화면 또는 작업표시줄에서 크롬 아이콘 찾기

빨간색, 노란색, 초록색, 파란색으로 이루어진 동그란 아이콘이 크롬입니다. 바탕화면에 있거나, 화면 아래쪽 작업표시줄에 있습니다.

[ Chrome 아이콘 — 빨강/노랑/초록/파랑 원형 아이콘 ]
2

크롬 아이콘을 더블 클릭

마우스로 크롬 아이콘 위에 커서를 놓고, 왼쪽 버튼을 빠르게 두 번 클릭합니다. 크롬 브라우저 창이 열립니다.

3

주소창 확인하기

브라우저 상단에 긴 흰색 입력칸이 보입니다. 이것이 주소창(주소 표시줄)입니다. 여기에 웹사이트 주소를 입력합니다.

[ 크롬 브라우저 상단의 주소창 위치 표시 ]
TIP: 크롬이 없다면? 마이크로소프트 엣지(Edge)나 네이버 웨일(Whale)을 사용해도 됩니다. 하지만 크롬이 가장 호환성이 좋습니다. 전산실 컴퓨터에는 이미 크롬이 설치되어 있습니다.

0-2. Gemini(제미나이) 접속 방법

Gemini는 구글(Google)이 만든 AI입니다. 구글 계정만 있으면 무료로 사용할 수 있습니다.

1

주소창에 입력하기

크롬 상단의 주소창을 마우스로 한 번 클릭합니다. 주소창이 파란색으로 선택됩니다. 그 상태에서 아래 주소를 키보드로 직접 입력합니다.

gemini.google.com

입력을 마쳤으면 키보드의 Enter(엔터) 키를 누릅니다.

2

구글 로그인하기

구글 로그인 화면이 나타납니다.

  • 이메일 입력칸에 구글 이메일 주소(예: myname@gmail.com)를 입력합니다.
  • "다음" 버튼을 클릭합니다.
  • 비밀번호 입력칸에 비밀번호를 입력합니다.
  • "다음" 버튼을 클릭합니다.
구글 계정이 없다면? 로그인 화면에서 "계정 만들기"를 클릭하면 새 계정을 만들 수 있습니다. 이름, 생년월일, 이메일, 비밀번호만 입력하면 됩니다. (약 2분 소요)
3

Gemini 화면 살펴보기

로그인이 완료되면 Gemini 메인 화면이 나타납니다.

Gemini 화면 구성 화면 중앙 아래쪽: 긴 입력칸이 보입니다. 이것이 바로 "프롬프트 입력창"입니다. 여기에 AI에게 보낼 메시지를 입력합니다.

입력칸 오른쪽: 종이비행기 모양의 보내기 버튼이 있습니다.

입력칸 왼쪽: + 버튼(파일/이미지 첨부), 마이크 버튼(음성 입력)이 있습니다.

왼쪽 사이드바: 이전에 나눈 대화 목록이 표시됩니다. "새 채팅" 버튼을 누르면 새로운 대화를 시작합니다.
[ Gemini 메인 화면 — 프롬프트 입력창, 보내기 버튼, 사이드바 위치 ]
4

첫 번째 메시지 보내보기

프롬프트 입력창을 클릭하고, "안녕"이라고 입력한 후 Enter 키를 누르거나 보내기 버튼(종이비행기)을 클릭하세요.

안녕

AI가 인사를 해줍니다. 축하합니다! 방금 AI와 첫 대화를 나누셨습니다!

0-3. ChatGPT(챗GPT) 접속 방법

ChatGPT는 OpenAI라는 회사가 만든 AI입니다. 무료로 사용할 수 있고, 전 세계에서 가장 많이 사용되는 AI입니다.

1

주소창에 입력하기

크롬 주소창을 클릭하고, 아래 주소를 입력한 후 Enter 키를 누릅니다.

chatgpt.com
2

회원가입 또는 로그인하기

ChatGPT 메인 화면이 나타나면:

  • 이미 계정이 있다면: "로그인(Log in)" 버튼을 클릭합니다.
  • 처음이라면: "가입하기(Sign up)" 버튼을 클릭합니다.

가입 방법 (처음인 경우):

  • "Google로 계속하기" 버튼을 클릭하면 가장 쉽습니다. (구글 계정으로 바로 가입됩니다)
  • 또는 이메일 주소를 입력하고 비밀번호를 설정합니다.
  • 이름을 입력하고 "계속"을 클릭합니다.
가장 쉬운 방법: "Google로 계속하기"를 클릭하면 구글 계정으로 바로 가입 + 로그인이 됩니다. 별도 비밀번호를 만들 필요가 없어요!
3

ChatGPT 화면 살펴보기

로그인이 완료되면 ChatGPT 메인 화면이 나타납니다.

ChatGPT 화면 구성 화면 아래쪽 중앙: "메시지를 입력하세요..."라고 적힌 입력칸이 보입니다. 이것이 프롬프트 입력창입니다.

입력칸 오른쪽: 위쪽 화살표 버튼(보내기)이 있습니다. 메시지를 입력하면 활성화됩니다.

입력칸 왼쪽: 클립 모양 버튼(파일 첨부)이 있습니다.

왼쪽 사이드바: 이전 대화 목록이 보입니다. "새 채팅"을 누르면 새 대화가 시작됩니다.

화면 상단: 현재 사용 중인 AI 모델 이름(예: GPT-4o)이 표시됩니다.
[ ChatGPT 메인 화면 — 프롬프트 입력창, 보내기 버튼, 사이드바 위치 ]

0-4. 문제가 생겼을 때 해결 방법

영어 화면이 나오는 경우 Gemini: 보통 자동으로 한국어가 설정됩니다. 만약 영어로 나오면, 프롬프트 입력창에 "한국어로 대화해줘"라고 입력하면 됩니다.

ChatGPT: 왼쪽 아래 본인 이름(또는 아이콘) 클릭 → "Settings(설정)" → "General(일반)" → "Language(언어)"에서 "한국어"를 선택합니다. 또는 그냥 한국어로 입력하면 한국어로 답변합니다.
"로봇이 아닙니다" 확인이 나오는 경우 정상적인 과정입니다! 체크박스를 클릭하거나, 보이는 이미지 퍼즐을 풀면 됩니다. "신호등이 있는 이미지를 모두 선택하세요" 같은 문제가 나오면, 해당 이미지를 클릭한 후 "확인"을 누르세요.
화면이 안 뜨거나 오류가 나는 경우 1) 인터넷 연결을 확인하세요. (다른 사이트, 예: naver.com이 열리는지 확인)
2) 주소를 정확히 입력했는지 확인하세요. (오타 주의!)
3) 브라우저 새로고침: 키보드에서 F5 키를 누르거나, 주소창 왼쪽의 새로고침(둥근 화살표) 버튼을 클릭하세요.
4) 그래도 안 되면 손을 들어 도움을 요청하세요!
비밀번호를 잊어버린 경우 로그인 화면에서 "비밀번호를 잊으셨나요?" (또는 "Forgot password?")를 클릭하세요. 가입할 때 사용한 이메일로 비밀번호 재설정 링크가 전송됩니다.
오늘 교육에서는 Gemini를 주로 사용합니다. 구글 계정만 있으면 바로 사용할 수 있고, 이미지 생성도 무료입니다. ChatGPT는 보조로 함께 사용합니다.

1 프롬프트란 무엇인가?

AI에게 말을 거는 방법, "프롬프트"의 개념을 처음부터 배워봅시다.

1-1. "프롬프트"라는 단어의 뜻

프롬프트(Prompt)란, AI에게 보내는 메시지, 질문, 요청을 말합니다.

쉽게 말하면:

한마디로 프롬프트 = AI에게 보내는 카톡 메시지

여러분이 카카오톡에서 친구에게 메시지를 보내듯, AI에게 텍스트를 입력하는 것이 바로 "프롬프트를 작성한다"는 뜻입니다.

AI 입력창에 타이핑하는 모든 글이 = 프롬프트입니다.

1-2. 카톡으로 이해하는 프롬프트

친구에게 카톡으로 부탁하는 상황을 상상해 보세요.

대충 부탁하면

나: "야, 밥 먹자"

친구: "언제? 어디서? 뭐 먹을 건데?"

정보가 부족해서 친구가 되물어봅니다.

잘 부탁하면

나: "내일 점심 12시에 도동항 근처 횟집에서 회정식 먹자!"

친구: "좋아! 내일 보자!"

구체적으로 말하니 바로 OK!

잘 부탁하면 좋은 결과, 대충 부탁하면 대충 결과
AI도 마찬가지입니다. 구체적이고 자세하게 요청할수록 원하는 결과가 나옵니다.

지금 바로 해봅시다! Gemini 또는 ChatGPT 화면으로 이동하세요.

프롬프트 입력창 클릭

화면 아래쪽의 입력창을 마우스로 클릭합니다. 커서가 깜빡이면 준비 완료!

2

"안녕"이라고 입력

키보드로 안녕이라고 입력합니다.

안녕
3

Enter 키를 눌러 전송

키보드의 Enter(엔터) 키를 누릅니다. 또는 입력창 오른쪽의 보내기 버튼을 클릭합니다.

4

AI 응답 확인하기

잠시 기다리면 AI가 응답합니다. 아래와 비슷한 답변이 나올 것입니다:

AI 예상 응답 안녕하세요! 반갑습니다. 무엇을 도와드릴까요? 궁금한 것이 있으시면 편하게 물어보세요.
축하합니다! 방금 여러분이 "안녕"이라고 입력한 것, 그것이 바로 프롬프트입니다! 아주 짧은 프롬프트를 작성하고 AI에게 보낸 것입니다.

이번에는 질문을 해봅시다.

1

프롬프트 입력창에 아래 내용을 입력합니다

울릉도가 어디야?
2

Enter 키를 누릅니다

3

AI 응답 확인하기

AI 예상 응답 울릉도는 대한민국 경상북도 울릉군에 속한 섬으로, 동해에 위치하고 있습니다. 한반도 동쪽 약 130km 해상에 있으며, 면적은 약 72.86km2입니다. 포항, 강릉, 묵호 등에서 여객선을 타고 갈 수 있으며, 약 2~3시간이 소요됩니다. 성인봉(984m)을 중심으로 한 화산섬으로, 아름다운 자연경관과 해산물이 유명합니다.
지금 무슨 일이 일어난 건가요? 여러분이 "울릉도가 어디야?"라고 질문(프롬프트)을 보냈더니, AI가 울릉도에 대한 정보를 찾아서 알려준 것입니다.

프롬프트(여러분의 메시지) → AI가 이해하고 분석 → 응답(AI의 답변)

이 과정이 AI와의 대화의 기본 구조입니다!

1-5. 정리: 이것이 프롬프트입니다!

프롬프트 = AI에게 보내는 모든 메시지
질문, 부탁, 요청, 명령 — AI 입력창에 타이핑하는 모든 것이 프롬프트입니다.

방금 여러분이 입력한 "안녕"도 프롬프트이고, "울릉도가 어디야?"도 프롬프트입니다.

지금부터 배울 내용은 "어떻게 하면 프롬프트를 더 잘 작성해서, AI에게서 더 좋은 결과를 받아낼 수 있는가"입니다.

기억하세요: 프롬프트를 잘 쓰는 것은 특별한 기술이 아닙니다. 친구에게 부탁을 구체적으로 잘 하는 것과 똑같습니다. 지금부터 그 방법을 하나씩 배워봅시다!

2 프롬프트 5원칙 — AI에게 잘 부탁하는 5가지 비법

이 5가지만 기억하면 AI를 200% 활용할 수 있습니다. 각 원칙마다 직접 실습해봅시다!

역할(Role) + 배경(Context) + 구체적 지시(Specificity) + 예시(Example) + 형식(Format)
5가지를 모두 넣을 필요는 없습니다. 상황에 맞게 2~3개만 조합해도 큰 차이가 납니다!
1

원칙 1: 역할을 정해주세요 (Role)

왜 역할이 중요할까요?

AI는 아무 역할 없이 대답하면 "백과사전"처럼 일반적인 답을 합니다. 하지만 역할을 주면 그 분야 전문가처럼 답변합니다.

일상 비유 식당에서 주문할 때:
"아무거나 주세요" → 뭐가 나올지 모릅니다.
"이 집에서 제일 인기 있는 해산물 요리 추천해주세요" → 딱 원하는 걸 추천받습니다.

AI에게도 "너는 ○○ 전문가야"라고 알려주면, 그 역할에 맞는 전문적인 답변을 합니다.

나쁜 예: 역할 없이 요청하기

성인봉을 소개하는 문구 만들어줘
AI 예상 출력 (역할 없을 때) 성인봉은 울릉도에 위치한 해발 984m의 산으로, 울릉도의 최고봉입니다. 다양한 식생이 분포하며, 정상에서 동해의 아름다운 풍경을 감상할 수 있습니다. 등산로가 잘 정비되어 있어 관광객들에게 인기가 있습니다.

왜 나쁜가요? → 백과사전 같은 딱딱한 설명이 나옵니다. 홍보용으로 쓸 수 없습니다.

좋은 예: 역할을 부여하고 요청하기

너는 울릉도 관광 마케터야. 성인봉을 소개하는 한 줄 문구 3개 만들어줘
AI 예상 출력 (역할 부여 시) 1. "구름 위에 서다 — 984m 성인봉에서 만나는 하늘과 바다의 경계"

원칙 2: 배경 정보를 알려주세요 (Context)

왜 배경 정보가 중요할까요?

AI는 여러분의 가게, 상황, 목적을 전혀 모릅니다. 처음 만난 사람에게 부탁하는 것과 같다고 생각하세요.

일상 비유 처음 만난 사람에게 부탁할 때:
"그거 해줘" → 상대방은 "뭘 해달라는 거지?" 하고 당황합니다.
"저는 울릉도에서 횟집을 하고 있는데, 우리 가게 메뉴판에 쓸 소개글이 필요해요. 대표 메뉴는 자연산 회정식이고, 관광객이 주 고객이에요." → "아, 그렇군요! 이렇게 써보면 어떨까요?"

AI에게도 상황, 목적, 조건을 자세히 설명할수록 정확한 결과가 나옵니다.

원칙 3: 구체적으로 요청하세요 (Specificity)

왜 구체적이어야 할까요?

"좋게 써줘"라고 하면 AI도 뭘 해야 할지 모릅니다. 숫자, 조건, 기준을 명확히 알려줘야 합니다.

일상 비유 음식을 주문할 때:
"맛있게 만들어주세요" → 사람마다 "맛있다"의 기준이 다릅니다.
"매운맛, 2인분, 밥 포함, 계란 추가요" → 정확하게 원하는 대로 나옵니다.

AI에게도 개수, 글자 수, 대상, 톤, 형식을 명확히 말해야 원하는 결과가 나옵니다.

원칙 4: 예시를 보여주세요 (Example)

왜 예시가 중요할까요?

사진을 보여주면서 "이렇게 해주세요" → 원하는 스타일이 정확하게 전달됩니다!

AI에게도 "이런 느낌으로 해줘"라고 예시를 보여주면, 그 스타일을 파악해서 비슷하게 만들어줍니다.

원칙 5: 결과 형식을 정해주세요 (Format)

왜 형식이 중요할까요?

같은 내용이라도 어떤 형식으로 받느냐에 따라 활용도가 완전히 달라집니다.

일상 비유 보고서를 요청할 때:
"울릉도 관광 현황 알려줘" → 긴 문장으로 나옴 → 읽기 힘듦
"울릉도 관광 현황을 표로 정리해줘" → 깔끔한 표 → 바로 사용 가능!

결과물의 형식을 미리 지정하면 AI가 딱 맞는 형태로 만들어줍니다.

자주 사용하는 형식들

기법 1: 단계적 요청 (체인 프롬프팅)

핵심 아이디어: 복잡한 요청은 한 번에 다 시키지 말고, 여러 단계로 나눠서 하나씩 요청하세요.

일상 비유 요리를 배울 때:
"해물 파전 만들어!" → 한 번에 다 하려면 어렵습니다.
"1단계: 재료 준비 → 2단계: 반죽 만들기 → 3단계: 굽기" → 하나씩 하면 쉽습니다!

AI에게도 복잡한 작업을 단계별로 나눠서 요청하면 각 단계의 결과가 훨씬 좋아집니다.
한 번에 다 요청 (비추천)

단계별로 요청 (추천)

1단계 → 2단계 → 3단계로 나눠서 하나씩!

→ 각 단계의 결과를 확인하고 다음으로 넘어가니 훨씬 좋습니다.

4-2. Gemini에서 이미지 만들기

Gemini는 텍스트뿐 아니라 이미지도 생성할 수 있습니다. 관광 포스터, SNS 썸네일 등을 직접 만들어봅시다.

알아두기: Gemini에서 이미지 생성을 사용하려면 Google 계정에 로그인되어 있어야 하며, "이미지를 만들어줘" 또는 "그림을 그려줘"라고 요청하면 됩니다. 사람 얼굴이 포함된 이미지는 생성이 제한될 수 있습니다.

좋은 이미지 프롬프트의 구조

주제 + 구도 + 스타일 + 색감 + 비율
이 5가지 요소를 조합하면 원하는 이미지를 정확하게 얻을 수 있습니다.
요소별 설명 주제: 무엇을 그릴지 (예: 울릉도 해안 절벽, 오징어 요리)
구도: 어디서 바라보는지 (예: 위에서 내려다본, 정면, 클로즈업)
스타일: 어떤 느낌인지 (예: 수채화, 사진, 미니멀, 일러스트, 포스터)
색감: 어떤 분위기인지 (예: 따뜻한 색감, 파스텔톤, 선명한)
비율: 이미지 크기 (예: 정사각형, 세로 3:4, 가로 16:9)

실습 1: 관광 포스터 이미지

울릉도 관광 포스터에 사용할 이미지를 만들어줘. 주제: 울릉도 해안 절벽과 에메랄드빛 바다 구도: 해안 절벽 위에서 바다를 내려다보는 시점 스타일: 선명하고 생동감 있는 여행 포스터 스타일 색감: 파란 바다, 초록 절벽, 맑은 하늘의 대비가 강렬하게 비율: 세로 3:4 비율
예상 결과 Gemini가 울릉도 해안 절벽과 에메랄드빛 바다가 담긴 세로형 이미지를 생성합니다. 이미지 아래에 "이미지 다운로드" 버튼이 나타납니다. 클릭하면 내 컴퓨터(다운로드 폴더)에 저장됩니다.

실습 2: SNS 썸네일 이미지

인스타그램 게시물용 정사각형 이미지를 만들어줘. 주제: 울릉도 자연산 오징어회가 접시에 담겨 있는 모습 구도: 위에서 내려다보는 탑뷰(top view) 스타일: 감성적인 음식 사진 스타일 색감: 따뜻한 조명, 나무 테이블 배경, 따뜻한 톤 비율: 정사각형 1:1

실습 3: 메뉴판 배경 이미지

식당 메뉴판 배경으로 사용할 이미지를 만들어줘. 주제: 울릉도 바다와 해산물이 어우러진 배경 구도: 넓은 전경, 텍스트를 올릴 수 있도록 중앙은 여백 스타일: 수채화 느낌의 부드러운 일러스트 색감: 파스텔톤 블루와 화이트 중심, 은은한 느낌 비율: 가로 A4 비율
이미지 저장 방법: 생성된 이미지 위에 마우스를 올리면 다운로드 아이콘이 나타납니다. 클릭하면 컴퓨터의 "다운로드" 폴더에 PNG 파일로 저장됩니다. 스마트폰에서는 이미지를 길게 누르면 "이미지 저장" 옵션이 나옵니다.

새벽 경매에서 직접 골라온 자연산 횟감, 섬에서만 맛볼 수 있는 따개비밥, 향긋한 명이나물... 오늘은 30년간 울릉도에서 식당을 운영하며 쌓은 경험을 바탕으로, 진짜 현지인만 아는 울릉도 맛집을 소개해드릴게요.

7 자주 하는 실수 & 해결법 (트러블슈팅)

AI를 사용하다 보면 이런 문제가 생깁니다. 당황하지 마세요! 아래 해결법을 따라하면 됩니다.

문제 1: "AI가 엉뚱한 답을 해요"

문제 상황 울릉도 홍보 문구를 부탁했는데 제주도 이야기를 하거나, 우리 가게와 전혀 상관없는 내용을 씁니다.
원인 AI에게 충분한 정보를 주지 않았기 때문입니다. AI는 우리 가게, 울릉도 상황을 모릅니다. 역할과 맥락이 부족하면 AI가 추측해서 답합니다.
해결 방법 프롬프트에 아래 정보를 추가하세요:

1. 역할 부여: "너는 울릉도 관광 마케팅 전문가야"
2. 구체적 맥락: "우리 가게는 울릉도 도동항 근처 해산물 식당이야"
3. 제한 조건: "울릉도 내용만 다뤄줘. 다른 지역 이야기는 하지 마"

또는: 이미 만든 GPT 앱을 사용하면 매번 설명할 필요가 없습니다! (파트 5 참고)

문제 2: "영어로 답변해요"

문제 상황 한국어로 질문했는데 영어로 답변이 나옵니다. 또는 중간중간 영어가 섞여 나옵니다.
원인 AI가 언어를 잘못 판단했거나, 이전 대화에서 영어를 사용한 기록이 남아있을 수 있습니다.
해결 방법 방법 1 (즉시): 같은 대화에서 이렇게 입력하세요.
→ "한국어로 다시 답변해줘" 또는 "모든 답변을 한국어로 해줘"

방법 2 (근본적): 프롬프트 맨 앞에 항상 이 문장을 넣으세요.
→ "한국어로 답변해줘."

방법 3 (GPT 앱): GPT 앱의 지시사항에 "기본 언어는 한국어. 번역 요청 시에만 외국어 사용"이라고 적어두면 됩니다.

문제 3: "너무 긴 답변이 나와요"

문제 상황 인스타 포스팅을 부탁했는데 A4 2장 분량의 글이 나옵니다. 블로그 글인지 논문인지 구분이 안 됩니다.
원인 분량을 지정하지 않으면 AI는 가능한 한 상세하게 답변하려고 합니다.
해결 방법 프롬프트에 분량을 구체적으로 지정하세요.

예시:
- "200자 이내로 써줘"
- "3줄로 요약해줘"
- "인스타 포스팅이니까 짧고 임팩트 있게 써줘"
- "핵심만 5개 항목으로 정리해줘"

이미 긴 답이 나왔다면: 같은 대화에서 "위 내용을 100자로 줄여줘"라고 추가 요청하세요.

문제 4: "이전 대화를 기억 못해요"

문제 상황 아까 우리 가게 정보를 알려줬는데, 다시 물어보면 모른다고 합니다. "아까 말했잖아!"
원인 "새 대화"를 시작하면 이전 대화 내용이 리셋됩니다. AI는 현재 대화 안에서만 내용을 기억합니다.
해결 방법 1. 같은 대화에서 이어서 질문하세요.
왼쪽 사이드바에서 이전 대화를 클릭하면 이어서 대화할 수 있습니다. "새 채팅"을 누르면 새로운 대화가 시작되어 기억이 사라집니다.

2. GPT 앱을 활용하세요 (근본적 해결!).
GPT 앱의 지시사항에 가게 정보를 미리 입력해두면, 새 대화를 시작해도 항상 우리 가게를 알고 있습니다. 이것이 GPT 앱의 가장 큰 장점입니다!

3. 대화 시작할 때 정보를 다시 알려주세요.
새 대화를 시작했다면, 맨 처음에 가게 정보를 한 번 더 알려주고 질문하세요.

문제 5: "이미지가 안 만들어져요"

문제 상황 Gemini에 "이미지 만들어줘"라고 했는데 텍스트 설명만 나오고 실제 이미지가 생성되지 않습니다.
원인 여러 가지 이유가 있을 수 있습니다:
- 로그인이 안 되어 있음
- 특정 내용(사람 얼굴, 유명인 등)은 이미지 생성이 제한됨
- 일시적인 서버 문제
- Gemini 버전에 따라 이미지 생성 지원 여부가 다름
해결 방법 1. 로그인 확인: 우측 상단 프로필 아이콘 확인. 로그인 안 되어 있으면 로그인하세요.

2. 프롬프트 수정: "이미지를 생성해줘" 또는 "그림을 그려줘"처럼 명확하게 요청하세요.

3. 사람 얼굴 제외: "사람이 없는 풍경 이미지"로 요청해보세요. 사람 이미지는 제한이 있을 수 있습니다.

4. ChatGPT 사용: Gemini에서 안 되면 ChatGPT의 DALL-E 이미지 생성을 사용해보세요. ChatGPT에서 "이 이미지를 만들어줘"라고 하면 됩니다.

5. 무료 이미지 생성 사이트: bing.com/images/create에서 Microsoft 계정으로 무료 이미지 생성도 가능합니다.

문제 6: "GPT 앱이 안 보여요"

문제 상황 GPT 앱을 만들었는데 찾을 수가 없습니다. 사이드바에도 없고, GPT 탐색에도 안 보입니다.
원인 - 다른 계정으로 로그인되어 있을 수 있음
- 저장을 안 했을 수 있음
- 브라우저 캐시 문제
해결 방법 1. 계정 확인: 좌측 하단의 프로필을 확인해서 GPT를 만들었던 계정으로 로그인되어 있는지 확인하세요.

2. GPT 탐색 → 내 GPT: 사이드바의 "GPT 탐색" 클릭 → 상단의 "내 GPT" 탭을 확인하세요. 여기에 내가 만든 모든 GPT가 나타납니다.

3. 직접 URL 접속: 주소창에 chatgpt.com/gpts/mine을 입력하면 내 GPT 목록으로 바로 갑니다.

4. 브라우저 새로고침: Ctrl+Shift+R (강력 새로고침)을 해보세요.

5. 다시 만들기: 위 방법으로도 안 되면, 파트 5를 참고해서 다시 만들면 됩니다. 이 가이드의 프롬프트를 복사-붙여넣기하면 5분이면 됩니다!
